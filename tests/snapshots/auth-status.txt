Usage: tweenframe auth status

Reads the stored identity (or TWEENFRAME_TOKEN) without calling the API and reports whether it can
be used: authenticated, expired, id, expires_at, source (file or environment) and auth_file. An
expired token makes every API command fail with auth_required; run `tweenframe auth init` to get a
new one.

Options:
  -h, --help                Show this help.

Output: JSON on stdout as {"data": ...}. Errors as {"error": {code, message, hint, docs}} on stderr,
        exit code 1.

Examples:
  tweenframe auth status

Docs: https://api.test/docs/agent/SKILL.md
