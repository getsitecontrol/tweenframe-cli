Usage: tweenframe recipes render <recipe> --input <json|file|-> [options]

Renders a recipe with your inputs and output options. Inputs are checked against the recipe's
`input_schema` and output options against OutputOptions; a rejected value is a 422 whose
`details.path` points at it. The answer is a completed render with `result_url`, or a pending job to
poll with `poll_url` (the CLI's `--wait` polls and `--output` downloads). Output options are not
inputs: with the CLI they are flags of this command.

The CLI checks --input, the output options and every file:// path locally before any request,
uploads each distinct local file once, sends the render, and with --wait or --output polls until it
completes or fails.

Arguments:
  recipe                    Recipe id from `recipes list`; append @<version> only to pin a version.

Options:
  --input <json|file|->     Required. Recipe inputs as a JSON object: inline JSON, a JSON file path,
                            or - for stdin. Start from an example in `tweenframe recipes show <id>`;
                            local images go in as file:// URLs at the recipe's asset_paths.
  --wait                    Poll until the render completes or fails and print the final render.
  --output <file>           Wait for completion and download the result to this file; parent
                            directories are created. Implies --wait.
  --format <gif|webp|apng|mp4|webm|png|jpeg|svg|pdf>
                            File format. Animated: gif, webp, apng, mp4, webm; still (first frame):
                            png, jpeg, svg, pdf. Default: the recipe's output.format.
  --quality <maximum|normal|minimal>
                            Encoder quality preset; lower quality gives a smaller file. Not for svg
                            or pdf. Default: the recipe's output.quality.
  --width <16..3000>        Output width in pixels; height follows the canvas aspect. Rescales the
                            rendered canvas, so one inputs object serves every size. An integer from
                            16 to 3000. Default: the recipe's output.width.
  --scale <number>          Multiplier of the canvas size; when set, width is ignored. Not for svg
                            or pdf. A number greater than 0. Default: the recipe's output.scale.
  --fps <0..30>             Frames per second, 0-30; 0 keeps the recipe's authored frame rate.
                            Animated formats only. A GIF keeps per-frame delays, so its effective
                            rate can be lower. A number from 0 to 30. Default: the recipe's
                            output.fps.
  --loop <true|false>       Whether the result repeats forever (true) or plays once; gif, webp and
                            apng only. Default: the recipe's output.loop.
  -h, --help                Show this help.

Output: JSON on stdout as {"data": ...}. Errors as {"error": {code, message, hint, docs}} on stderr,
        exit code 1.

Examples:
  tweenframe recipes render real-estate/banner-7 --input inputs.json --wait --output out/banner.gif
  tweenframe recipes render before-after/default --input inputs.json --format mp4 --wait --output out/compare.mp4
  tweenframe recipes render animated-text/loop --input - --format webp --width 600 --wait --output out/title.webp < inputs.json
